# Meow Gallery

## サイト概要
猫の写真を投稿・閲覧し、猫好きなユーザー同士で交流できるSNSサイトです。

### サイトテーマ
猫のかわいい写真を共有し、いいねやコメントを通じて交流できる猫専用SNSサイト

### テーマを選んだ理由
私は猫が好きで、かわいい猫の写真を見ることが好きです。

一般的なSNSではさまざまなジャンルの投稿があるため、猫の写真だけを気軽に楽しめる場所があれば便利だと考えました。

また、猫を飼っている人が自分の猫の写真を共有したり、猫を飼っていない人でも写真を楽しんだりできるサイトを作りたいと思いました。

そこで、猫好きな人同士が写真を通じて交流できるSNSサイト「Meow Gallery」を制作することにしました。

### ターゲットユーザー
- 猫が好きな人
- 自分の飼っている猫の写真を共有したい人
- かわいい猫の写真を見て癒やされたい人
- 猫好きなユーザー同士で交流したい人

### 主な利用シーン
- 休憩時間や空き時間に猫の写真を見て癒やされたい時
- 自分の猫のかわいい瞬間を他の人に共有したい時
- 気に入った猫の写真にいいねをして、後から見返したい時
- 他のユーザーの投稿にコメントして交流したい時
- 気になるユーザーをフォローして、投稿を楽しみたい時

## 主な機能
- ゲストログイン機能
- ユーザー登録・ログイン・ログアウト機能
- 猫の写真の投稿・編集・削除機能
- 投稿一覧・詳細表示機能
- 投稿検索機能（キーワード検索）
- ユーザー検索機能
- コメント機能
- 管理者によるユーザー管理機能
- いいね（ブックマーク）機能
- いいね（ブックマーク）一覧表示機能
- フォロー・フォロー解除機能
