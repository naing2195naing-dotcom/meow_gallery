
# 🐱 Meow Gallery

**Every Meow ^-^ Has a Story**

Little paws, endless happiness.  
小さな肉球、大きな幸せ。

## サイト概要

Meow Galleryは、猫の写真を投稿・閲覧し、猫好きなユーザー同士で交流できるSNSサイトです。

### サイトテーマ

猫のかわいい写真を共有し、いいねやコメントを通じて交流できる猫専用SNSサイトです。

### テーマを選んだ理由

私は猫が好きで、かわいい猫の写真を見ることで癒やされています。

一般的なSNSではさまざまなジャンルの投稿があるため、猫の写真だけを気軽に楽しめる場所があれば便利だと考えました。

また、猫を飼っている人が愛猫の写真を共有したり、猫を飼っていない人でも猫の写真を楽しんだりできるサイトを作りたいと思いました。

そこで、猫好きな人同士が写真を通じて交流し、日常の中で小さな幸せを感じられるSNSサイト「Meow Gallery」を制作することにしました。

### ターゲットユーザー

- 猫が好きな人
- 自分の飼っている猫の写真を共有したい人
- かわいい猫の写真を見て癒やされたい人
- 猫好きなユーザー同士で交流したい人

### 主な利用シーン

- 休憩時間や空き時間に猫の写真を見て癒やされたい時
- 自分の猫のかわいい瞬間を他の人に共有したい時
- 気に入った猫の写真にいいねをして、後から見返したい時
- 他のユーザーの投稿にコメントして交流したい時
- 気になるユーザーをフォローして、投稿を楽しみたい時
